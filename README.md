# 📚 ISTQB CTFL Study Hub com NotebookLM

Este repositório foi criado com o objetivo de centralizar e potencializar os estudos para a certificação **ISTQB CTFL (Certified Tester Foundation Level)** utilizando o **NotebookLM** como ferramenta de apoio.

---

## 🎯 Objetivo

Transformar o conteúdo oficial do ISTQB em uma experiência de aprendizado mais eficiente, dinâmica e contextualizada, utilizando recursos de IA para:

- Geração de resumos inteligentes
- Criação de perguntas simuladas
- Exploração de conceitos complexos
- Conexão entre diferentes tópicos da certificação

---

## 📦 Base de Conhecimento

A base foi construída a partir de fontes relevantes e confiáveis:

- 📄 Documentação oficial do ISTQB (CTFL)
- 🎥 Vídeos de especialistas e profissionais da área de Qualidade de Software
- 🧠 Conteúdos complementares para reforço conceitual

---

## 🚀 Como utilizar com NotebookLM

O NotebookLM permite explorar o conteúdo de forma ativa e personalizada:

- Gerar resumos de capítulos ou temas específicos  
- Criar perguntas e simular provas  
- Tirar dúvidas com base no conteúdo carregado  
- Relacionar conceitos entre diferentes áreas do CTFL  
- Revisar conteúdos com foco em pontos de dificuldade  

---

## 🧩 Público-alvo

Este material é indicado para:

- Iniciantes em QA  
- Analistas de Testes  
- Engenheiros de Qualidade  
- Profissionais que desejam obter a certificação ISTQB CTFL  

---

## ⚙️ Estratégia recomendada de estudo

1. Estudar o conteúdo oficial do ISTQB  
2. Utilizar o NotebookLM para reforçar entendimento  
3. Gerar perguntas e validar conhecimento  
4. Identificar gaps e revisar pontos críticos  
5. Repetir o ciclo até atingir consistência  

---

## 📌 Importante

Este projeto não substitui o material oficial do ISTQB.  
Seu objetivo é **potencializar o aprendizado**, tornando o estudo mais eficiente e direcionado.

---

## 📈 Diferencial do projeto

- Uso de IA aplicada ao estudo estruturado  
- Aprendizado ativo (não apenas leitura passiva)  
- Possibilidade de adaptação ao ritmo de cada pessoa  
- Exploração mais profunda dos conceitos de qualidade
